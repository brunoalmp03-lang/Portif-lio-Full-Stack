Portfólio de Tecnologia - MVP
1. Nome e Descrição do Projeto
Nome do Projeto: Portfólio Executivo de Tecnologia

Descrição: Trata-se de uma aplicação web estática, leve e responsiva desenvolvida para centralizar a trajetória profissional, formação acadêmica, habilidades técnicas e portfólio de código. O projeto atende tanto o desenvolvedor, substituindo currículos dispersos em PDF, quanto recrutadores e gestores, acelerando a triagem corporativa e permitindo avaliar rapidamente a qualificação e encontrar canais de contato diretos em poucos cliques.

3. Tecnologias Utilizadas
HTML5: Estruturação semântica das seções (Cabeçalho, Hero, Experiência, Projetos, Tech Stack, Formação e Rodapé).

CSS3: Estilização visual, tipografia, estruturação de layout utilizando CSS Grid e Flexbox, e adaptação Mobile-First.

JavaScript Puro (Vanilla JS): Implementação de interações leves (como navegação âncora suave / smooth scrolling).

Git e GitHub: Controle de versão e hospedagem pública da aplicação via GitHub Pages.

4. Instruções para Executar o Portfólio
Como este é um projeto estático desenvolvido com tecnologias web nativas, ele não requer instalação de dependências ou servidores complexos (como Node.js ou Python). Siga os passos abaixo para executá-lo localmente:

Clone o repositório ou faça o download dos arquivos compactados em sua máquina:

Bash
git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
Abra a pasta do projeto em seu editor de código preferido (ex: VS Code).

Dê um duplo clique no arquivo index.html para abri-lo diretamente em qualquer navegador web moderno (Google Chrome, Firefox, Edge, Safari).

Dica: Se utilizar o VS Code, você pode instalar a extensão Live Server e clicar em "Go Live" no canto inferior direito para visualizar o projeto com atualização automática a cada salvamento.

5. Resumo das Funcionalidades
Menu de Navegação e Smooth Scrolling: Links no cabeçalho que levam o usuário suavemente até a seção desejada da página.

Resumo Técnico (Hero Section): Seção de destaque inicial com apresentação direta, cargo pretendido e especialidade.

Experiência Profissional: Histórico cronológico detalhando empresas, cargos, períodos de atuação e atividades realizadas.

Projetos de Destaque: Vitrine de sistemas desenvolvidos com redirecionamento para o GitHub.

Pilha Tecnológica (Tech Stack & Skills): Listagem objetiva de competências técnicas e comportamentais.

Formação e Certificações: Seção dedicada a graduações, cursos e certificados.

Links Dinâmicos de Contato: Botões interativos para redirecionamento imediato a perfis profissionais (LinkedIn, GitHub) e disparo de e-mail via mailto:.

Design Responsivo (Mobile-First): Layout adaptável para leitura fluida em smartphones, tablets e computadores de diferentes resoluções.
