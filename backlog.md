# Backlog

## Histórias gerais

### Administrador
- [Must Have] Como administrador, quero apresentar minhas principais experiências profissionais no portfólio, informando empresas, cargos, períodos e atividades realizadas, para demonstrar minha trajetória e experiência na área.

Critério de aceitação: O portfólio deve apresentar empresa, cargo, período de atuação e principais atividades realizadas de forma clara e organizada.

- [Must Have] Como administrador, quero apresentar minha formação acadêmica, cursos e certificações no portfólio, para demonstrar minha qualificação e conhecimento profissional.

Critério de aceitação: O portfólio deve apresentar curso, instituição, período de formação e cursos ou certificações relevantes.

- [Must Have] Como administrador, quero apresentar minhas principais habilidades técnicas e comportamentais, para destacar minhas competências e facilitar a avaliação do meu perfil profissional.

Critério de aceitação: O portfólio deve apresentar habilidades como liderança, comunicação, organização, planejamento e trabalho em equipe.

- [Must Have] Como administrador, quero disponibilizar meus dados de contato no portfólio, para facilitar que recrutadores interessados possam entrar em contato comigo.

Critério de aceitação: O portfólio deve apresentar pelo menos uma forma de contato atualizada, como e-mail, telefone ou LinkedIn.

### Recrutadores

- Como recrutador, quero visualizar as experiências profissionais do administrador, para avaliar sua trajetória e verificar se possui experiência compatível com a vaga.

Critério de aceitação: O recrutador deve conseguir visualizar facilmente os cargos, empresas, períodos e principais atividades realizadas.

- Como recrutador, quero consultar a formação acadêmica, cursos e certificações do administrador, para avaliar seu nível de qualificação profissional.

Critério de aceitação: As informações sobre formação, cursos e certificações devem estar disponíveis e organizadas no portfólio.

- Como recrutador, quero visualizar as habilidades técnicas e comportamentais do administrador, para verificar se seu perfil atende às necessidades da oportunidade.

Critério de aceitação: As principais habilidades do candidato devem estar apresentadas de forma clara e objetiva no portfólio.

- Como recrutador, quero encontrar os dados de contato do administrador, para poder entrar em contato caso tenha interesse em seu perfil profissional.

Critério de aceitação: O portfólio deve disponibilizar dados de contato atualizados e de fácil localização.

## Histórias mais especificas

- [Should Have]Como desenvolvedor(a) de tecnologia, quero exibir uma seção de projetos de destaque com links diretos para os repositórios no GitHub e demonstrações ao vivo (Live Demo), para comprovar na prática a qualidade do meu código e a entrega de valor técnico.

- Critério de aceitação: Cada card de projeto deve conter título, breve descrição do problema resolvido, tecnologias utilizadas (em formato de badges), link funcional para o repositório no GitHub e botão de acesso à demonstração, garantindo navegação rápida para o recrutador.

- [Could Have] Como recrutador(a) técnico(a), quero filtrar os projetos exibidos por linguagem ou ferramenta específica (ex: JavaScript, HTML/CSS, Git), para verificar rapidamente se o candidato possui experiência na stack tecnológica exigida pela minha vaga.

- Critério de aceitação: O portfólio deve conter botões de filtro interativos manipulados via JavaScript puro, ocultando ou exibindo dinamicamente os cards de projetos correspondentes sem a necessidade de recarregar a página.

- [Could Have] Como recrutador(a) técnico(a), quero alternar entre o modo escuro (Dark Mode) e o modo claro (Light Mode) na interface, para garantir conforto visual durante a leitura prolongada do portfólio.

- Critério de aceitação: A página deve disponibilizar um botão de alternância de tema no cabeçalho. Ao ser acionado, o script em JavaScript deve alterar as variáveis de cores do CSS instantaneamente e salvar a preferência no armazenamento local (localStorage) do navegador.
